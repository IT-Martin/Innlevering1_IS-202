Martin:

Ai hva den mener med de kode linjenen. Å skrivet inn direkte eller endre koden til AI.

Begrunnelsen for jeg skriver inn direkte meste enn å copy/paste. Er for å få overført det jeg lærer fra korttids mine til langtidsminnen. 
Jeg syns det er alt for lett å kopiere idag til en annet sted. Å målet er å bruke tid og lære hvordan man koder og logikken rundt det. Fordi ting tar tid å lære seg dette.

Jeg startet med å bruke Copilot GTP-5.6 Luna. Men det kom en del kode som jeg kanskje ikke trengte å en del feil.
Bestemte meg å bruke GPT-6 Astra. Fikset koden mye lettere, og mye lettere å lese og endre koden. Enn Copilot.
